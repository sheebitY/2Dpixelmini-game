# Pixel Quest - 像素冒险

一款基于 PixiJS 的 2D 像素风格 RPG 小游戏，使用 TypeScript + Vite 构建。

## 游戏特色

- **8 张地图**：草原村庄、森林小径、湖畔营地、沙漠前哨、地下巢穴、森林空地、山间要道、远古遗迹
- **多种怪物**：史莱姆、老鹰、骷髅、兽人、哥布林（4种变体），按地图分级
- **装备系统**：武器、头盔、胸甲、护腿、靴子，从骨制→铁制→钢制→龙鳞逐级升级
- **制作系统**：收集材料在铁匠处打造装备
- **商店系统**：向商人购买药水和消耗品
- **等级系统**：击杀怪物获得经验值，升级提升属性
- **存档系统**：自动保存进度，支持读档

## 操作方式

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| J / 鼠标左键 | 攻击 |
| E / 空格 | 与 NPC 对话 |
| I | 打开/关闭背包 |
| B | 打开/关闭商店 |
| M | 下一张地图 |
| R | 复活（死亡后） |
| Esc | 设置 |

## 技术栈

- **渲染引擎**：PixiJS 7
- **语言**：TypeScript
- **构建工具**：Vite 6
- **架构**：ECS（实体-组件-系统）

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
`

## 项目结构

`
src/
  core/        # 核心系统（事件总线、输入管理、精灵加载、存档）
  ecs/         # 实体-组件-系统架构
  scenes/      # 游戏场景（主游戏逻辑）
  combat/      # 战斗系统
  items/       # 物品数据库、装备、制作
  ui/          # 界面（HUD、背包、商店、对话框）
  world/       # 地图管理、碰撞检测
assets/
  sprites/     # 角色/怪物/NPC 精灵图
  tilesets/    # 地图瓦片
  maps/        # 地图数据（JSON）
  audio/       # 背景音乐和音效
  ui/          # UI 图标和素材
`
