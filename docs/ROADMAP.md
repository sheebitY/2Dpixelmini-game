# Roadmap

## Phase 0 - Setup
- Initialize web project (static or Vite).
- Add placeholder assets and test scene.

## Phase 1 - Core Loop
- Player movement + collision.
- Enemy spawn + simple AI.
- Basic combat and HP bars.

## Phase 2 - RPG Systems
- Level progression and stat scaling.
- Equipment system and inventory.
- Quest accept/complete flow.

## Phase 3 - Boss & Dungeon
- Boss phases and attack patterns.
- Reward chest and milestone tracking.

## Phase 4 - Persistence
- IndexedDB save manager.
- Save version migration system.
- Autosave + manual save slots.

## Phase 5 - Polish
- UI improvements (dialog, quest log, minimap).
- Audio and visual juice (hit shake, particles).
- Mobile touch input support.

## Phase 6 - Live Content
- More maps and enemy variants.
- Loot affixes and item rarity tiers.
- Optional cloud sync.
